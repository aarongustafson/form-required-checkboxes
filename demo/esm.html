<form-required-checkboxes> via esm.sh

Import the class and register it manually. README

The checkboxes work before enhancement. Selection-count validation needs JavaScript; if the module doesn’t load, follow the limits in the legend. Applications must also validate selections on the server.

Manual registration

The class-only import doesn’t register the element. Call customElements.define() once before using it. 

import { FormRequiredCheckboxesElement } from
  'https://esm.sh/@aarongustafson/form-required-checkboxes@3.2.5/form-required-checkboxes.js?bundle&target=es2022';

if (!customElements.get('form-required-checkboxes')) {
  customElements.define(
    'form-required-checkboxes',
    FormRequiredCheckboxesElement
  );
}
