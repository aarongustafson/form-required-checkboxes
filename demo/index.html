<form-required-checkboxes>

Require an exact count, a range, or an optional maximum of native checkbox selections. See the README for installation and API documentation.

Read the README View on GitHub esm.sh example unpkg example

The checkboxes work before enhancement. Selection-count validation needs JavaScript; if the module doesn’t load, follow the limits in each legend. Applications must also validate selections on the server.

Require an exact count

Set required="3" on the component to require exactly three selections. Wrap labeled, same-name checkboxes in a fieldset with a legend.

Submit with fewer or more than three selections to see the browser’s validation message. The browser can focus the first checkbox; changing a checkbox clears the custom error. Reset restores selections, but does not clear an existing custom error. Change a checkbox before submitting again after an invalid attempt.

Native required on an individual checkbox requires that checkbox, not a count across the group. Other invalid fields can stop native submission before group validation runs. See the required-email example.

Include a required native field

Submit with an empty email field: the browser reports that field’s native error before the group’s submit handler runs. Enter a valid email address and submit again to check the selection count.

Match your application’s vocabulary

Translate group messages

Set lang to use built-in messages. Translate the authored legend, labels, buttons, and result text too. These example forms are translated; the surrounding tutorial and shared code controls remain in English.
